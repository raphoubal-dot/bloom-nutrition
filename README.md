# Bloom 🌸

Bloom est un journal alimentaire personnalisé, développé en HTML, CSS et JavaScript pour une utilisation sur iPhone dans Safari.

🐈‍⬛ **Bloomie** est la mascotte de l'application. Direction visuelle : florale, crème, sauge, pêche et lavande.

## Ouvrir l'application

https://raphoubal-dot.github.io/bloom-nutrition/

## Fonctionnalités en développement

- Configuration du profil et des objectifs nutritionnels
- Journal alimentaire par date (petit-déjeuner, déjeuner, dîner, en-cas)
- Aliments personnels, recettes, poids et pas
- Scanner de codes-barres, recherche Open Food Facts et import d'étiquettes

## Confidentialité

Le dépôt est public, mais le journal personnel n'y est **pas** stocké. Les données sont conservées localement dans le navigateur. Utiliser les sauvegardes JSON pour les conserver avant d'effacer les données de Safari.

> Application en développement. Les informations nutritionnelles et les objectifs calculés restent des estimations.
